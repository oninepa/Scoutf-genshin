# 지니 자동 학습 시스템 (GENIE AUTOLEARN)

질문 로그 → 클러스터링 → LLM 초안 → 검수 → 자동 배포

**업계 표준 FAQ 자동 생성 파이프라인. 완전 자동은 아니지만 90% 자동화 가능.**

---

## 왜 필요한가

**문제:**

- 사용자 질문은 무한
- 템플릿 손으로 만들면 끝없음
- 새 캐릭터/이벤트마다 수동

**해결:**

- 질문 로그 수집
- 빈도순 패턴 파악
- LLM이 초안 생성
- 사람이 검수
- 자동 배포

---

## 5단계 파이프라인

### 1단계: 수집 (매일, 자동)

**사용자 질문 → 서버 로그 → DB 저장**

```javascript
// server.js에 추가
// POST /chat/local, /chat/llm, /chat/ai 호출 시
fs.appendFileSync(
  "logs/questions.jsonl",
  JSON.stringify({
    q: input,
    at: new Date().toISOString(),
    type: "quick" | "ai",
    uid: uid,
  }) + "\n"
);
2단계: 분석 (주 1회, 자동)
로그 → 의미 클러스터링 → TOP 50

javascript
// analyze-questions.js
// 1. logs/questions.jsonl 읽음
// 2. 질문 정규화 (소문자, 공백 제거)
// 3. 의미 기반 그룹화 (LLM 또는 임베딩)
// 4. 빈도순 정렬
// 5. TOP 50 출력
예시:

text
레진 어디 쓸까?           (100회)
레진 쓸 곳?               (50회)
레진 어떻게?              (30회)
   ↓
클러스터: "레진 사용" (180회)
3단계: 생성 (주 1회, LLM)
TOP 50 클러스터 → LLM → 템플릿 초안

javascript
// generate-templates.js
// 각 클러스터의 대표 질문 + 답변 요구사항
// LLM에게 요청:
// "이 질문에 대한 템플릿 만들어줘.
//  - 키워드 3~5개
//  - 조건 (facts 참조)
//  - priority 1~10
//  - 답변 문장 (지니 톤)"
LLM 초안 (80% 정확도) → 사람 검수 (95%)

4단계: 배포 (30개 쌓이면, 자동)
templates.enc 생성 → 서버/GitHub 업로드 → 앱 자동 패치

Tauri Updater 방식:

text
1. GitHub Releases에 latest.json 업로드
2. 앱이 주기적으로 체크
3. 새 버전 있으면 알림
4. 클릭 → 자동 다운로드 → 설치
Folo (실제 사례):

text
- GitHub Releases = 발행 소스
- Cloudflare Workers = 배포 레이어
- Cron = 5분마다 동기화
5단계: 검증 (계속, 자동)
새 템플릿이 실제 질문 커버하는지 추적

text
템플릿 30개 추가 → 2주 후
   ↓
"이 중 20개는 잘 쓰임, 10개는 안 쓰임"
   ↓
안 쓰이는 것 제거, 더 필요한 것 추가
배포 방식 (하이브리드)
방식	장점	단점
사용자 PC 설치	오프라인, 빠름	패치 필요
서버 실시간	항상 최신	인터넷 필요
하이브리드:

기본 템플릿: 사용자 PC에 .enc (오프라인)

새 템플릿: 서버에서 실시간 다운로드 (선택)
```
