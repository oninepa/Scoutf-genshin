# GENIE-SYSTEM.md — 지니 시스템 설계

**작성:** 2026-09-24
**목적:** 게임 무관 AI 도우미 시스템 (원신, LoL, 기타 게임 재사용)

---

## 1. 철학

### 문제

- LLM은 느리고, 환각이 있고, 429에 걸림
- 템플릿은 빠르고 정확하지만, 심심함
- **둘 다 필요** — 상황에 따라

### 해결

- **템플릿** (런타임 90%): 빠르고 정확
- **LLM** (런타임 10%): 어려운 질문
- **다듬기**: 템플릿 답변을 LLM이 자연스럽게
- **검증**: LLM 답변을 코드가 감시
- **이벤트**: 백그라운드에서 "먼저 말 검"

## 3. 런타임 흐름

### 사용자 질문

[⚡ 간단 빨리]
→ template-engine
→ 매칭됨: 템플릿 답변
→ 매칭 안 됨: "AI 상세를 눌러주세요"

[🧠 AI 상세]
→ template-engine 먼저 시도
→ 매칭됨: polisher (LLM 다듬기)
→ 매칭 안 됨: LLM 새 답변
→ validator (검증)
→ 문제 있으면: 재시도 or 템플릿 폴백

### 백그라운드 (살아있는 지니)

[10분마다]
→ event-watcher
→ games/{게임}/events.js 로드
→ 이벤트 감지
→ 사용자 설정 필터링
→ 알림 큐에 저장

[사용자 접속]
→ 큐 확인
→ "여행자님, 파견 5개 완료됐어요!"

## 4. 프로필 설정 (사용자 선택)

### 피드백 주기

- 안 함
- 1분 (너무 잦음)
- 5분
- **10분** (기본)
- 30분

### 피드백 종류

- **중요사항만** (레진 가득, 파견 완료)
- 전부 다
- 성유물만
- 나선만
- 이벤트만

### 알림 방식

- **텍스트** (채팅창)
- 음성 (TTS)
- 알림창 (OS)

### 답변 스타일 (AI 상세)

- 팩트만 (숫자 그대로)
- **친근하게** (지니 톤)
- 상세 분석
- 짧게

### 프리셋

- **게임 집중** — 중요만, 5분, 텍스트
- 일상 — 전부, 30분, 알림창
- 학습 — 전부, 10분, 텍스트+음성
- 조용히 — 안 함

## 패턴 라이브러리 (게임 무관)

패턴 1: "3층 방어"
[템플릿] → 정확
↓
[LLM 다듬기] → 자연스러움
↓
[검증] → 환각 차단
적용: 원신, LoL, 모든 게임

패턴 2: "이벤트 감시"
[백그라운드] → 상태 변화 감지
↓
[필터링] → 사용자 설정
↓
[전달] → 텍스트/음성/알림
적용: 레진 가득, 파견 완료, 첫 킬

패턴 3: "우선순위 큐"
🔴 긴급 (즉시) — 레진 가득
🟡 중요 (5분) — 일일 미완
🟢 일반 (합쳐서) — 업적
적용: 알림 피로 방지

패턴 4: "사용자 학습"
2주 후 → "이 알림 자주 무시하셨어요. 줄일까요?"
적용: 자동 우선순위 조정

패턴 5: "다중 모드"
[⚡ 간단 빨리] → 템플릿
[🧠 AI 상세] → 템플릿 + 다듬기
[🔊 음성] → 템플릿 + TTS
[🎯 분석] → LLM + 검증
적용: 사용자 선택

패턴 6: "게임별 플러그인"
engine/ (공통)
games/genshin/ (플러그인 1)
games/lol/ (플러그인 2)
games/val/ (플러그인 3)
적용: 새 게임 = 폴더만 추가

패턴 7: "캐시 레이어"
[템플릿 답변] → 로컬 캐시
[LLM 답변] → 서버 캐시 (선택)
적용: 같은 질문 재요청 시 빠름

패턴 8: "A/B 테스트"
답변 A (템플릿) vs 답변 B (LLM 다듬기)
→ 사용자 반응 수집
→ 더 좋은 것 채택
적용: 답변 품질 개선

패턴 9: "폴백 체인"

1. 템플릿 (정확)
2. LLM 새 답변 (자연스러움)
3. 캐시된 유사 답변
4. 기본 fallback ("준비 중")
   적용: 무조건 답변 보장

패턴 10: "컨텍스트 주입"
[질문] + [팩트] + [이전 대화]
↓
[LLM] → 상황 인식 답변
적용: "내 파티 왜 약해?" 같은 복잡한 질문

패턴 11: "음성 최적화"
[답변 텍스트]
↓
[TTS 최적화] → 마크다운 제거, 숫자 한글화
↓
[음성 재생]
적용: 음성 모드

패턴 12: "알림 배치"
5개 알림이 1분 내 도착
↓
[배치] → "파견 5개 완료, 레진 가득, 일일 3개 남음"
적용: 도배 방지
