## 2026-09-21 (세션 2)

- Groq 모델: `groq/compound-mini` (속도 1.8초, 429 없음)
- 일일 파싱: 5회 → 10회
- 자동 파싱: 30분마다 체크, 2시간 경과 시 실행 (서버 켜져 있을 때만)
- 언어 구조: 언어별 빌드 분리 (`languages/{ko,en,ja,zh}/`)
  · 언어팩: 프롬프트 + 로컬브레인 + 미션 + 용어사전
  · 이유: 속어/게임용어/밈이 언어별로 완전 다름
  · 언어 전환은 추후 (재설치 없이 되면 좋지만 필수 아님)
- 미션 뱅크: 320 → 480개 (카테고리당 20 → 30)
- 미션 제안: LLM 2차 답변에 1개씩 자연스럽게 섞기
- AI 연결 버튼: 홈화면 하단 (LLM이라는 단어 대신 "AI 연결")
- play 창: decorations false, transparent true, 상단 56px 드래그 바
- 투명도: `.play-app` 배경 알파만 조절 (카드/글씨는 그대로)
- 추천 질문: 3 → 6개 (3열 2줄 그리드)
- 계정 최대: 2개 (확정, 구현 완료)

### 2026-09-21 (언어 구조 확정)

- 언어 처리 방식: **언어별 빌드 분리** (설치 시 언어 선택)
- 구조: `languages/{ko,en,ja,zh}/` — 언어팩에 프롬프트 + 로컬브레인 + 미션 + 용어사전 포함
- `advisor/`는 순수 로직 (언어 중립)
- 이유: 속어/게임용어/밈은 언어별로 완전히 다름. 번역은 절반만 하면 안 됨
- 언어 전환은 추후 (재설치 없이 되면 좋지만 필수 아님)
- 기본은 `ko/`에서 개발. `en/ja/zh`는 나중
