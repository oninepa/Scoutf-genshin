# AI 작업 규칙 (항상 가장 먼저 읽기)

1. 작업 시작 전 순서대로 읽는다: `INDEX.md` → `STATE.md` → `docs/10-rules.md`
2. INDEX.md가 안내하는 문서만 추가로 읽는다. 폴더 전체를 뒤지지 않는다.
3. 한 번에 태스크 하나만 한다. 범위를 넓히지 않는다.
4. 수정 전에 "어떤 파일을 어떻게 바꿀지"를 먼저 말한다. 요청 범위 밖은 건드리지 않는다.
5. 기존 파일은 통째로 다시 쓰지 말고 필요한 부분만 수정한다.
6. 작업이 끝나면 반드시 `STATE.md`를 갱신하고, 바뀐 내용이 있으면 관련 docs도 갱신한다.
7. 방향이나 구조가 바뀌면 `docs/DECISIONS.md`에 한 줄 기록한다. 기록된 결정은 임의로 되돌리지 않는다.
8. 같은 오류를 2번 고치려다 실패하면 멈추고 사용자에게 알린다. 그 위에 수정을 쌓지 않는다.
9. 확실하지 않으면 추측해서 진행하지 말고 질문한다.
10. 작업 시작 전과 끝날 때 git 커밋을 제안한다.
11. 새로 시작한 AI(모델 교체 포함)는 `docs/11-handoff.md`의 절차를 따른다.
