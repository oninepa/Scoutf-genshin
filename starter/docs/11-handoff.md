# 11 모델 교체 / 새 대화 시작 절차

## A. 모델을 바꾸기 전에 (기존 AI에게)
```
지금까지 작업을 STATE.md 최신 버전으로 갱신해 줘.
완료, 작동 안 하는 것, 다음 할 일, 최근 바꾼 파일, 방향이 바뀐 내용(DECISIONS.md)까지 포함해서.
```
그리고 git 커밋을 한다.

## B. 새 AI에게 첫 명령 (그대로 붙여 넣기)
```
CLAUDE.md, INDEX.md, STATE.md, docs/10-rules.md, docs/DECISIONS.md를 읽어.
아무것도 수정하지 말고, 지금 프로젝트 상황을 5줄로 요약해.
내가 OK하기 전에는 시작하지 마.
```
요약이 틀리면 바로잡은 뒤 시작한다.

## C. 새 AI가 엉뚱하게 만들어 놓았을 때
1. 고치려 하지 말고 마지막 정상 커밋으로 되돌린다 (`git reset --hard`).
2. 새 대화에서 B부터 다시 시작한다.
3. 같은 오류를 2번 고쳐도 안 되면 무조건 이 절차를 쓴다.

## D. 작은 수정 전용 (싼 모델)
```
CLAUDE.md, docs/10-rules.md, docs/04-design-system.md만 읽어.
[파일명]의 [무엇]만 [이렇게] 바꿔. 다른 건 건드리지 마.
```
